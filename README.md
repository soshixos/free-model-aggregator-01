One server, two APIs, ten free providers: the best free AI model aggregator. It serves OpenAI Chat Completions and Anthropic Messages, in JSON and streaming, routing each request to the highest-rated free model that meets it, across OpenAI, Anthropic and Gemini wires, with failover when a provider's free tier is spent.

## Run it

```sh
node main.ts
```
